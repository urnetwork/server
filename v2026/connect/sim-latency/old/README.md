# Archived sim-latency material

This directory contains superseded planning documents, calibration runbooks,
campaign utilities, and preview reports retained for provenance. Nothing here
is part of the current evaluator build, production entrypoint, test gate, or
live-deployment procedure.

The active competition sources are one directory above. In particular:

- `README.md` describes the current simulator and scoring commands;
- `OFFICIAL-RUN.md` and `official-run.sh` define the evaluator contract;
- `PLAYBOOK.md` and `playbook.yml` define live operation;
- `baseline/final-baseline.html` is the final human-readable baseline report;
- `baseline/` preserves the authenticated calibration evidence.

Archived scripts may refer to ignored local run directories and should not be
used to operate a competition epoch.
